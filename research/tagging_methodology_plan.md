# Tagging Methodology Plan

## Purpose
This note outlines the tagging methodology for analyzing song titles and lyrics. The current approach uses manual content tagging as a baseline with embedding-based classification as a possible extension.

## 1. Current Baseline: Manual Tagging
The current tagging template organizes song title and lyric information into structured variables related to content themes, emotion, localization, and data availability.

## 2. Limitation: Keyword Ambiguity
Title keywords alone may be insufficient for content classification because some titles are metaphorical or context-dependent. Lyric context is needed to interpret the theme.

## 3. Possible Extension: Embedding-Based Classification
Embedding-based classification can be explored to compare titles and lyrics by semantic similarity, especially when keyword-based tagging is ambiguous.

## 4. Next Step
Use the manual tagging results as a baseline and explore embedding-based methods for ambiguous theme classification.
