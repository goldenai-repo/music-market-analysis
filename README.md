# AI-Generated Music Market Analysis

Research and analysis project exploring AI music generation and streaming platform data.

## Project Goals

### 1. Suno Research
- Background, company history, and product overview
- Key product characteristics and differentiators
- How to use Suno to generate music (prompting techniques, genre/style controls)
- Hands-on: generate sample tracks and document the experience

### 2. DistroKid Research
- Overview of DistroKid as a music distribution platform
- How artists publish music to streaming platforms via DistroKid
- Pricing, features, and royalty handling

### 3. Streaming Platform Data Fetching
Explore what data is publicly available from platforms such as iTunes, YouTube Music, Spotify, and others.

#### 3.1 Data Availability Report
Document what can and cannot be fetched from each platform's API or public data sources. Saved as a written report.

#### 3.2 Tooling Setup
Set up coding assistance CLI (Claude Code, GitHub Copilot, etc.) for development workflow.

#### 3.3 Python Data Fetcher
Implement Python scripts to fetch music and musician data from available APIs.

#### 3.4 Data Analysis
Analyze the collected data — trends, genre distributions, artist metrics, etc.

#### 3.5 Presentation
Compile findings into a slide deck.

## Repo Structure (planned)

```
music-market-analysis/
├── research/          # Written reports and notes (Suno, DistroKid, API availability)
├── src/               # Python scripts for data fetching and analysis
├── data/              # Raw and processed data files
```
