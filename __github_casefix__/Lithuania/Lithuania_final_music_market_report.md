# Lithuania Music Market and Local-Language Song Launch Report

Date: 2026-06-14

## 1. Project Objective

This report answers three questions:

1. Is Lithuania a suitable market for digital music release testing?
2. Is there market acceptance for Lithuanian local-language / local-artist songs?
3. If we release local-language songs, which styles should be prioritized?

Research logic:

1. First, assess whether Lithuania has a digital music consumption foundation.
2. Then, assess whether Lithuanian local-language / local-artist songs are accepted by the market.
3. Next, use popular songs across all languages to identify mainstream style preferences.
4. Finally, select styles where Lithuanian lyrics can be paired with sounds already validated by Lithuanian listeners.

### One-Sentence Conclusion

For a Lithuania local-language release, the first batch should prioritize Lithuanian pop / alt-pop, with one melodic hip-hop / pop-rap track and one dance-pop / electronic track used as comparison tests.

## 7. Final Release Recommendation

### 7.1 Should We Release?

Yes, but through a small-scale multi-track test. A large-budget single-song bet is not recommended at the start.

Reasons:

- Lithuania has a digital music consumption foundation.
- Local / Lithuanian artists perform strongly on both Spotify and AGATA.
- YouTube search data shows long-tail playback for Lithuanian-language music, especially pop and rap.

### 7.2 Recommended Style Priorities

| Priority | Style | Reason |
|---:|---|---|
| 1 | Lithuanian pop / alt-pop | Strong across Spotify + AGATA + YouTube |
| 2 | Lithuanian melodic hip-hop / pop-rap | Strong local validation and second-strongest YouTube long-tail playback |
| 3 | Lithuanian dance-pop / electronic | Has Spotify/AGATA market presence; suitable for summer / streaming tests |
| 4 | Lithuanian emotional pop ballad | Can be tested as a pop sub-direction |
| 5 | Lithuanian indie / alternative | Differentiation test, not the mainline |

### 7.3 First-Batch Test Track Recommendation

| Track | Style | Language | Test purpose |
|---|---|---|---|
| A | Lithuanian pop / alt-pop | Lithuanian | Mainline test for broad acceptance and long-term retention |
| B | Lithuanian melodic hip-hop / pop-rap | Lithuanian | Test younger streaming listeners and YouTube long-tail potential |
| C | Lithuanian dance-pop / electronic | Lithuanian + short English phrase | Test summer / streaming / playlist potential |
| D | Lithuanian emotional pop ballad | Lithuanian | Test love / emotional themes and YouTube long-tail playback |

If only three tracks can be tested first, prioritize A, B, and C.

### 7.4 Song Direction

Lithuanian pop / alt-pop:

- BPM: 90-115
- Mood: romantic, bittersweet, night/city, youth
- Structure: main melody should appear within the first 15 seconds; chorus should be clear and memorable
- Production: modern pop, soft synth, guitar texture, clean drums

Lithuanian melodic hip-hop / pop-rap:

- BPM: 80-105 or double-time feel
- Mood: melancholic, confident, relationship-driven
- Structure: sung hook + short rap verse
- Production: trap drums, warm bass, piano/synth motif

Lithuanian dance-pop / electronic:

- BPM: 118-128
- Mood: summer, night-out, playful
- Structure: short intro, strong chorus/drop
- Production: house/dance-pop, 2000s synth, club beat

### 7.5 Not Recommended as Mainline Directions

| Style | Reason |
|---|---|
| Pure traditional / folk | Current Spotify/AGATA/YouTube samples do not provide enough support for a mainline direction |
| Pure experimental alternative | Differentiated, but lacks enough mainstream validation |
| Pure English international pop | Loses local-language differentiation and competes directly with international songs |
| Dance/electronic only | Testable on Spotify/AGATA, but YouTube long-tail is weak |

## 8. Final Conclusion

Lithuania can support local-language releases, but the strategy should not be "local language only." The stronger strategy is:

**Lithuanian lyrics + mainstream styles already validated by Lithuanian listeners.**

Final priority:

1. **Lithuanian pop / alt-pop**  
   The most stable direction, supported by Spotify + AGATA + YouTube.

2. **Lithuanian melodic hip-hop / pop-rap**  
   Second priority, with strong YouTube long-tail playback and existing local urban/rap audience signals.

3. **Lithuanian dance-pop / electronic**  
   Testable, especially for streaming and summer contexts, but not the YouTube long-tail mainline.

One-sentence conclusion:

**For a Lithuania local-language release, the first batch should prioritize Lithuanian pop / alt-pop, with one melodic hip-hop / pop-rap track and one dance-pop / electronic track used as comparison tests.**
